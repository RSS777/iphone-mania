# Labels de Triagem

As skills falam em termos de cinco papéis canônicos de triagem. Este arquivo mapeia esses papéis para as strings de label reais usadas no rastreador de issues deste repo.

| Label em mattpocock/skills | Label no nosso rastreador | Significado                              |
| --------------------------- | -------------------------- | ----------------------------------------- |
| `needs-triage`               | `needs-triage`              | Precisa ser avaliada                      |
| `needs-info`                 | `needs-info`                | Esperando mais informação                 |
| `ready-for-agent`            | `ready-for-agent`           | Totalmente especificada, pronta pra agente|
| `ready-for-human`            | `ready-for-human`           | Requer implementação humana               |
| `wontfix`                    | `wontfix`                   | Não será feita                            |

Quando uma skill mencionar um papel (ex: "aplicar a label de pronto-pra-agente"), use a string de label correspondente desta tabela.
